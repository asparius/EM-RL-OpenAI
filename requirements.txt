# ---------------------------------------------------------------------------
# PyTorch built against CUDA 12.8.
#
# Driver 570.x reports "CUDA Version: 12.8". A torch wheel built against a NEWER
# CUDA fails at init with "The NVIDIA driver on your system is too old", and the
# failure is quiet: torch.cuda.is_available() returns False and every rank falls
# back to CPU rather than erroring. The launch scripts preflight for exactly this.
#
# The pin below carries the +cu128 LOCAL VERSION, and that is the part doing the
# work. A plain floor like `torch>=2.7.0` is satisfied by whatever is already
# installed — including a wrong-CUDA build — so pip leaves it in place and the
# environment stays broken until someone remembers --force-reinstall. An exact
# +cu128 pin mismatches any other build and gets reinstalled automatically.
#
# For a different driver, change cu128 in BOTH the index URL and the pin
# (cu126, cu129, ...). Check with: nvidia-smi | grep "CUDA Version"
# To move torch versions, keep the +cu128 suffix. Available cu128 builds:
# 2.7.0 2.7.1 2.8.0 2.9.0 2.9.1 2.10.0 2.11.0
# ---------------------------------------------------------------------------
